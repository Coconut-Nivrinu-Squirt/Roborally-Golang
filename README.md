# Roborally Web implementation written in the go language
## Licensed under AGPL V3. License included as the file LICENSCE.md and visible in the tab beside the README tab.
### Built for use with postgresql as the database backend
 *This project is a heavy work in progress. Things may change randomly!!!*
This is built as a faithful recreation of the 2005 roborally ruleset that is Free to redestribute basis based on publically findable assets.
Some things (Like option cards and other things) are referrenced to a physical copy of the game, and accuracy is intended to be as close as possible.
A 2005 Roborally rulebook PDF was originally sourced from [RoboRally_Rules.indd PDF document @ device.report](https://device.report/m/42e0664e774ee4f6ba50694e436e27a631629e0c726daaeaf13337b801393219)
## Intended House rules
Course manual player count forced minimum 2, forced maximum 8 (Non Team)
Course manual player count as a reccomendation (Since this generally gets ignored when selecting maps
